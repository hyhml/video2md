# 版本记录

## 开发者工具 0.1.3 — 2026-09-10

- 建立 revise 提示词压力测试 v0.2.0：固定执行模型、输入、输出 schema、字幕对照与语义改动审计。
- 在已完成候选中，`B 证据门控` 的字幕一致性从 4/8、4 处编辑改善到 5/8、3 处编辑，且未发现无依据事实替换；设为默认修订策略。
- 将不确定文字写入 `notes` 的规则升级为证据门控，禁止因“更顺”而改写。

## 开发者工具 0.1.2 — 2026-09-10

- 新增 revise v0.1.0 对照评测：同一原稿的润色式改写与最小修订版本均可复核。
- 新增通用 `evaluate_revision.py`，统一使用基准的自由前后缀字符编辑距离对齐。
- 记录最小修订基线：28 条字幕样本从 22 条完全一致、7 处编辑改善至 26 条完全一致、3 处编辑。

## 开发者工具 0.1.1 — 2026-09-10

- 新增可组合的 Codex skills：`video2md-asr`、`video2md-revise`、`video2md-structure` 与总控 `video2md`。
- ASR skill 对接已验证的本地 CLI；修订、结构化 skill 固化 `transcript.json` → `revised.json` → `document.md` 的工件契约。
- 根据首次评测，将修订默认策略收紧为“最小修订”，避免流畅化改写破坏已有正确文本。

## 用户包 0.1.0 — 2026-09-10

- 发布第一环节“本地视频/音频 → 中文初稿”。
- 默认 Paraformer-zh（速度优先），支持 `--model nano` 切换 Fun-ASR-Nano-2512（质量优先）。
- 输出 TXT、粗时间轴 SRT、JSON 和可追踪的逐片段 JSONL。
- 建立 `user` 精简分支与 `main` 开发者模式的双分发方式。

## 基准 v0.2.0 — 2026-09-10

- 同一段 899.936 秒中文视频、16 kHz 单声道音频、固定 30 秒无重叠切片。
- 不使用热词、外部 VAD、标题或参考字幕提示；固定中文识别。
- 质量以 28 条预先固定的画面可见字幕（628 个规范化字符）做抽样字符编辑距离比较。
- 选择 Fun-ASR-Nano-2512 和 Paraformer-zh 进入用户包：前者质量最高，后者速度最快。
