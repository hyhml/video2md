# 版本记录

## 用户包 0.1.0 — 2026-09-10

- 发布第一环节“本地视频/音频 → 中文初稿”。
- 默认 Paraformer-zh（速度优先），支持 `--model nano` 切换 Fun-ASR-Nano-2512（质量优先）。
- 输出 TXT、粗时间轴 SRT、JSON 和可追踪的逐片段 JSONL。
- 建立 `user` 精简分支与 `main` 开发者模式的双分发方式。

## 基准 v0.2.0 — 2026-09-10

- 同一段 899.936 秒中文视频、16 kHz 单声道音频、固定 30 秒无重叠切片。
- 不使用热词、外部 VAD、标题或参考字幕提示；固定中文识别。
- 质量以 28 条预先固定的画面可见字幕（628 个规范化字符）做抽样字符编辑距离比较。
- 选择 Fun-ASR-Nano-2512 和 Paraformer-zh 进入用户包：前者质量最高，后者速度最快。
