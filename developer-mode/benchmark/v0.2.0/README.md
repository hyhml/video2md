# ASR 基准 v0.2.0

测试日期为 2026-09-10，设备为 RTX 3060 Laptop GPU（6 GiB）。测试输入为一段 899.9358125 秒的中文视频；输入视频 SHA-256：

`8c28abb4e8b864ed799936d05389cdafaefd47bf0e0f9451b6b4304d982b42dd`

## 协议

- 输入统一为 16 kHz、单声道 float32 音频。
- 固定连续 30 秒、无重叠切片；模型间不传递前一块文本。
- 强制中文；无热词、无外部 VAD、无标题/参考字幕提示。
- 转写时间不含下载、模型加载、预热、输入读取和最终文件导出。
- 质量参考为 28 条预先固定的画面可见字幕，共 628 个规范化字符。对相邻转写窗口计算最小字符编辑距离。

“字幕样本分歧率”不是完整音频 CER：画面字幕可能不同于口语，且样本外的错误不计入。所有结论需辅以人名、数字、缩写、否定句和专业术语的人工回听。

Fun-ASR-Nano-2512 是本轮抽样质量最高者；Paraformer-zh 是明显最快者。因此两者进入用户包，默认 Paraformer-zh。

对“社会主义、共产主义、马克思、苏联、美国、资本主义”等出现于该视频中的词汇作输出检索，六份完整本地文本都保留了大量匹配，未见系统性删词。这仅针对本视频、本地基础配置；不能推广为任何云服务或全部政治话题的审查结论。
