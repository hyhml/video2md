# 开发者模式

这里保存用户包的设计依据和可复核的基准摘要，用于后续模型、协议和工作流的迭代。它不是用户安装路径；普通用户应使用 [`user` 分支](https://github.com/hyhml/video2md/tree/user)。

## 内容

- `CHANGELOG.md`：仓库和用户包的版本演进。
- `architecture.md`：各工作流环节的边界与当前 ASR 接口。
- `benchmark/v0.2.0/`：六模型统一测试的协议、结果摘要和模型指纹。
- `evaluations/revise-v0.1.0/`：第二环节的原稿/修订稿对照、失败案例与最小修订基线。
- `evaluations/revise-v0.2.0/`：同一执行模型下的多提示词压力测试、字幕对照和语义改动审计。

## 发布规则

1. 用户包版本遵循语义化版本：破坏命令/输出兼容性时升主版本；新增兼容功能时升次版本；修复时升修订版本。
2. 基准版本独立管理：改变输入、切片、解码、计时或质量方法时升基准版本；仅增加模型且协议不变时升次版本。
3. 每个进入比较表的模型必须记录仓库、revision 或权重 SHA-256、依赖版本、设备与完整参数。
4. 不修改已经发布的基准结果；新跑测在新目录发布，并说明是否可与旧版横比。
5. `user` 分支由 `user-mode/` 生成。发布前在 `main` 更新用户包、运行冒烟测试，再用 `git subtree split --prefix=user-mode -b user` 更新该分支。

原始视频、模型权重、完整转写和私有环境均不提交。基准摘要可复核模型选择，但不能替代完整人工听写评测。
