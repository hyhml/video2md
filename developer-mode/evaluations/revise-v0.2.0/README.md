# revise 提示词压力测试 v0.2.0

本测试筛选 `video2md-revise` 的默认提示词，不测试 ASR 模型。执行模型固定为 **gpt-5.6-terra**（Codex 0.153.4，2026-09-10）；每次请求只含同一份 `stress-input.json` 和候选提示词，明确禁止读取字幕、视频、网页或其他文件。

## 固定样本与指标

压力样本取自 Fun-ASR-Nano-2512 的 8 个 30 秒片段，覆盖引语、政治表述、制度缩写、截断、机械重复及明显错字。`stress-reference.json` 是事后才使用的 8 条原视频可见字幕。

字幕指标使用与 ASR 基准相同的自由前后缀 Levenshtein 对齐；它只衡量局部文字一致性。真正的任务目标是语义准确，因此还对每个实际改动人工审计：

- **安全改动**：只删机械重复或修正不改变命题的明确错字/标点；
- **语义风险**：没有充分语境依据却替换事实性词语、术语、主语或立场；
- **待回听**：不确定的词被保留，并写入 `notes`，不计作修正成功。

原始 ASR：4 / 8 条字幕完全一致，4 处编辑，分歧率 2.02%。可见字幕不是完整人工听写稿，所以本测试不能宣称完整音频的真实准确率；最终发布前仍应抽样回听音频。

## 结果

| 提示词 | 有效输出 | 完全一致 | 编辑数 | 人工语义审计 | 结论 |
| --- | --- | ---: | ---: | --- | --- |
| A 最小修订 | 是 | 4 / 8 | 5 | 2 处无充分依据的词义替换 | 淘汰 |
| B 证据门控 | 是 | 5 / 8 | 3 | 未见无依据事实替换 | **当前默认** |
| C 两阶段 | 否 | — | — | 模型服务未产出 JSON | 待复跑 |
| D 可读性受约束 | 是 | 4 / 8 | 5 | 未见明显事实替换，但多处不必要的表达改动 | 不选 |

B 的有效改动包括删除机械的“是是”、删除连续重复句、修复“格瓦拉拉”。它将不确定的 `DFS/BFS`、人名和截断句保留在原文并写入 `notes`。A 则把“反应”改成“反映”、把“公认物质利益”改成“工人物质利益”，这类改动不能从输入独立确定，因此即使文本更顺，也不符合语义准确优先的要求。

## 复跑

1. 运行 `make_stress_sample.py` 生成固定输入与事后参考。
2. 用 `build_request.py` 将任一 `prompts/*.md` 和输入组合为自包含请求。
3. 使用固定模型与 `stress-output.schema.json` 调用修订执行器；先跑 `validate_candidate.py`。
4. 用 `../../evaluate_revision.py` 与 `stress-reference.json` 评分，并人工审阅文字差异。

`candidates/` 和 `scores/` 保存了本次三个有效候选；`C` 没有候选文件，因为没有产生可验证输出。
